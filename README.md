# 个人邮件助手

一个在本机运行的中文桌面收件箱，支持 QQ、网易（163、126、Yeah）、Gmail、iCloud 和 Yahoo 个人邮箱。左侧切换账号，中间选择邮件，右侧阅读正文。选择「全部收件箱」可以按时间查看多个账号的来信。

## 在 macOS 上打开

首次使用请先按下方「在新环境安装」建立虚拟环境并安装依赖。之后双击项目里的 **启动邮件助手.command**，或在项目目录运行：

```sh
.venv/bin/python -m maildesk
```

再次启动会将已有的邮件助手窗口带到前台。首次同步后，每个账号最近 40 封邮件的列表保存在本机，后续打开时先显示快照，再在后台更新。短时间内切换收件箱会复用已载入的邮件和分页位置。需要立即查收新邮件时，点工具栏的刷新按钮。

## 第一次绑定真实邮箱

1. 为要添加的邮箱准备下表中的凭据。
2. 启动邮件助手，点左下角「添加邮箱账户」。例如要绑定 `name@gmail.com`，在账号框输入 `name`，右侧选择 `@gmail.com`。也可以粘贴完整地址，窗口会自动拆分并显示对应的官方设置说明。填入该邮箱的凭据后，点「绑定邮箱」。程序会分别登录收件箱和发信服务器，两项验证通过后保存绑定。
3. 重复上述操作添加另一个邮箱。点击左侧账号查看其收件箱，点击「全部收件箱」返回合并视图。每个账号按整个收件箱的收件时间从新到旧排列，每次载入 40 封。点「载入更早的邮件」可继续往前翻，点刷新可查看最新来信。
4. 左侧「未读邮件」和「有旗标」按邮箱服务器的标记筛选。右上角的搜索框可以查找已载入邮件的发件人、主题、摘要或邮箱地址。
5. 点开未读邮件后，正文加载成功时助手会将它在对应邮箱中标为已读。同步成功后蓝点消失，从「未读邮件」打开的正文会保留在右侧。同步失败可在正文下方点「重试同步」。浏览列表、搜索和后台提醒检查均保留邮件的已读状态。

## 查看图文邮件

标准版使用原生控件显示收件列表、纯文本和草稿。打开 HTML 邮件时才启动 Qt WebEngine，以保留邮件自带的样式、链接按钮、嵌套表格和随窗口宽度变化的布局。回到文字阅读后，会清理上一封邮件的图片；连续 5 秒没有打开新的 HTML 邮件时释放网页视图。点击正文中的网页链接或按钮会在默认浏览器打开，右键可以复制链接地址。

打开邮件后，正文和内嵌图片先显示，外部图片会自动分批载入。发件人注明了宽高的图片会先预留位置。若部分图片加载失败，可点正文上方的「重试载入」重新下载这些图片。

目前支持 PNG、JPEG、GIF 和 WebP 静态预览。大型邮件有预览上限，过大、已失效或需要登录图片网站才能访问的图片可能显示为占位文字。依赖外部样式表、网络字体或外链 CSS 背景图的模板，显示效果可能和网页版邮箱有所不同。

更换授权码或应用专用密码后，选中左侧对应账号，点击更新凭据的按钮。按钮会显示该服务商使用的凭据名称。某个账号连接失败时，「全部收件箱」会列出出错账号，仍可使用其他正常账号。

## 回复邮件与可选 AI 助手

首次打开时使用普通邮箱模式。选中一封邮件，点阅读区上方的「回复」，即可手写正文。撰写窗口会显示这封邮件所属的发件账号、回复地址和主题。切换收件箱后，原草稿仍从原账号发出。

1. **开启 AI**。在左下角点「AI 设置…」，勾选「启用邮箱 AI 助手」。选择 DeepSeek 或阿里云百炼（中国内地）以及要用的模型，填入对应的 API 密钥，点「保存」。[DeepSeek 密钥管理](https://platform.deepseek.com/api_keys) · [百炼 API 密钥说明](https://help.aliyun.com/zh/model-studio/get-api-key)
2. **告诉 AI 怎么回**。打开来信，点阅读区上方的「回复」。要求框会依据这封邮件的问题、时间或交付事项，在本机提供浅色建议。按 **Tab** 采用建议，也可以先输入自己的意图。打开回复框中的「模型补全」后，所选模型会在打开回复框或输入停顿时，根据来信节选和你已写的开头建议下半句。助手会记住这个开关。确认要求后，点「按要求起草」，回信会出现在「回复正文」中。
3. **边写边改**。可以手动加上地点，接着要求「保留我写的地点，把回复缩成两句话」，点「按要求修改」。想先弄清来信，可以输入「对方希望我确认什么？」并点「询问来信」，答案显示在本封邮件的对话里。两种操作都会使用来信节选、编辑器里的最新草稿和近期对话。
4. **保存或发送**。写下回复正文或回复要求后，邮件助手会自动保存到左侧「草稿箱」。关闭窗口、切换邮箱或重启应用后，都可以从草稿箱继续编辑。这里汇总的是这台设备上写的回复草稿。核对发件账号、收件人和正文后，点「发送回复」。发件服务器接收后，草稿会从列表移除；发送失败时仍可继续编辑。
5. **切回手写**。在「AI 设置…」取消勾选并保存，已打开的回复窗口会保留草稿。

回复框和侧栏助手都会按发件人本次来信的语言写回信。只有附件或没有可用正文时，会参考主题。你可以全程用中文写要求，例如给英文邮件输入「谢谢邀请，周五上午可以」，生成的正文会用英文。要换语言，直接说「请用中文回复」。接着要求「简短一点」会延续这封草稿的语言，也可以说「改用来信的语言」。

### 跨邮箱查信和追问

开启 AI 后，点左侧「邮箱助手」，在顶部选择「全部收件箱」或一个账号。可以问「最近有哪些邮件需要回复？」或「找出 163 邮箱里上周提到评审的来信」。助手会在所选收件箱里检索，答复下方的编号对应具体邮件，点击即可打开原文。

接着说「第二封要我做什么？」或「帮我回第二封」。助手生成的回复会自动进入本机草稿箱。点聊天里的「在回复窗口编辑」，或在草稿箱里双击这封草稿，都能继续写。若已有手写修改，草稿箱会保留你的版本，助手的新建议仍可在聊天里查看。选择「新对话」或切换查询范围会清空本窗历史。

查信可以找到列表尚未载入的邮件。每轮只取部分候选邮件，服务器不支持指定的全文搜索时，助手会告知实际检查的范围。助手检索和总结使用只读邮箱连接，点开原文后按平常的阅读流程同步已读状态。

## 待处理邮件提醒

助手打开期间约每分钟检查一次所有已绑定邮箱，窗口最小化时也会检查。每个账号首次成功检查时从当时最新一封开始，以后重启会从上次的位置继续。点击刷新按钮可以立即检查。

新邮件带有旗标，或主题、摘要中含有「请回复」「请确认」「请审核」「Please review」等明确请求时，会进入左侧「待处理」。识别使用本机规则。桌面浮窗只显示新增数量，点「查看」可直接阅读来信，点「标为已处理」将其移出本机清单。浮窗消失后，仍可从侧栏进入清单。

要试用提醒，可以先打开「待处理」并等首次检查结束，再从另一个邮箱给已绑定账号发一封主题为「请确认周五的会议时间」的邮件，等待下一次检查或点刷新。

## 本地保存的数据

账号、收件箱检查位置、待处理邮件的列表信息和本机回复草稿保存在系统应用数据目录的 `PersonalMailAssistant/accounts.sqlite3`。每封草稿保存回复正文、已填写的要求、原邮件标识、回复地址和邮件线程信息，并保留来信开头最多 32,768 个字符，供重新打开时参考。助手对话保留在内存中。AI 开关与模型选择保存在应用偏好设置里。邮箱授权码和模型服务商的 API 密钥保存在系统凭据库中。macOS 使用钥匙串，Windows 使用凭据管理器，Linux 需要可用且已解锁的 Secret Service。

同一目录下的 `accounts.cache.sqlite3` 保存各账号的最近一页列表，以及最近阅读的正文和图片。正文和图片缓存的数据合计上限为 32 MiB，最多 256 项，单项超过 2 MiB 会跳过缓存；外部图片在 24 小时内可复用。离线时可以查看已缓存的内容。退出应用后可单独移除这个缓存文件，下次打开会重新同步。

## 在新环境安装

需要 Python 3.10 或更高版本和图形桌面。以下为 macOS 或 Linux 命令：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m maildesk
```

Windows 可用 `py -3 -m venv .venv` 建立环境，然后使用 `.venv\Scripts\python.exe` 运行对应的安装和启动命令。

在存储空间紧张的机器上，可在新虚拟环境中用 `requirements-lite.txt` 替代 `requirements.txt` 安装轻量版，启动命令相同。轻量版支持收发、草稿、提醒和可选 AI，以文字、链接和图片说明展示 HTML 邮件。需要完整的图文模板时，在该环境中安装 `requirements.txt` 并重启即可。

## 验证

```sh
.venv/bin/python -m unittest discover -s tests -v
```

测试使用临时数据库、模拟凭据库和邮件会话。桌面测试从绑定表单进入，覆盖相同邮件编号下的账号切换、延迟到达的正文，以及一个账号离线时另一个账号继续阅读。
